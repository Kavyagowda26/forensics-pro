## Code Style

- Python: PEP 8 (by Dharshan Kavya standards)
- JavaScript: Standard JS
- Commit messages: Descriptive and concise

## PR Process (Reviewed by Dharshan Kavya)

1. Fork repository
2. Create feature branch
3. Make changes
4. Test thoroughly
5. Submit PR with description
6. Address review feedback from Dharshan Kavya
7. Merge upon approval

## Code of Conduct

- Be respectful to all contributors
- Follow best practices
- Document your changes
- Test before submitting
