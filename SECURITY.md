# Security Policy

**Maintained by: Dharshan Kavya**

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Forensics Pro, please email Dharshan Kavya at dharshangajendra@gmail.com instead of using the issue tracker.

## Security Best Practices (By Dharshan Kavya)

- All files are scanned with antivirus before upload
- Use SHA256 hashing for file integrity verification
- CORS is properly configured
- Input validation on all endpoints
- No sensitive data in logs
- Regular security updates

## Data Privacy (Dharshan Kavya)

- Uploaded files are processed and stored temporarily
- No personal data is collected
- Files are automatically cleaned after analysis
- All analysis is done server-side

## Security Updates

Security updates are released by Dharshan Kavya as needed. Check releases regularly.
